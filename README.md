# NKG 红利研究工作台

从**中证红利指数 100 只成分**初筛，核查财报与分红，按悲观/基准/较好情景比较税前股息率参考价；随后记录模拟交易，或由你在中信证券 APP 手动下单并回填成交。

研究方法来自 [dividend-stock-research](https://github.com/wqaetly/dividend-stock-research)，不是 ETF 均线策略。允许没有合格候选。历史股息率只作背景，价格跌到参考价也不会自动买入。

**不连接券商、不保存证券账户密码、不自动发单。** 初次运行只创建虚拟资金账本；手动实盘账本必须自行初始化。Python 3.10+，仅使用标准库，无需安装依赖。

## 开始使用

在仓库目录执行（Windows PowerShell）：

```powershell
# 首次使用：复制配置，再填入你已有的服务凭据；已有 .env 则跳过此步
Copy-Item .env.example .env

# 每个交易日北京时间 21:00 后运行；首轮约数分钟，随后同日重复运行使用缓存
python -X utf8 -m qmt daily
Invoke-Item .\data\dashboard.html
```

本机本次安装已经创建 `.env`，不要覆盖。Tushare 直接使用 HTTP API，搜索使用 SearXNG 的 `/search?format=json` 和 `X-API-Key`，模型使用兼容的 `/chat/completions`。DeepSeek 默认关闭思考模式用于生成简短研究草稿。凭据、行情、账本和报告均被 Git 忽略；仓库只包含配置样例。

也可运行 `powershell -File .\start.ps1` 完成更新并打开报告。21:00 前会明确暂停；节假日显示最近完整交易日，不能从休市日/旧报告新增计划。`--refresh` 可重新获取当日数据，用于晚到或修订数据。缺少字段、日期不符、接口无权限时会显示缺口，不用旧价冒充新价。

只查看已有结果：

```powershell
python -X utf8 -m qmt report
```

候选表支持按公司、代码、行业查找，点击每行展开多年财务、分红、情景价及研究草稿。数据按代码排列，不按股息率做“最优股票”排名。成分使用 Tushare 最新月度权重快照，页面明确标注快照日期；取到不足 100 只或超过 45 天的成分数据会暂停。`daily --limit 3` 仅供排查接口，页面会明确显示覆盖 3/100。

## 联网与 AI 研究

从报告中选择一家公司，下面代码只演示命令形式，不代表推荐：

```powershell
python -X utf8 -m qmt research 000157.SZ
```

程序通过已有搜索服务寻找年报、分红政策和季报线索，并将**公开公司数据**和这些线索交给已配置模型。不会发送账本、持仓、账户密码或其他凭据。草稿会显示在该公司展开页中，保留来源编号、链接、搜索时间与错误提示。

搜索结果是线索，当前程序不自动下载和阅读公告 PDF；须打开原始公告核对。AI 不能改研究确认、参考价格公式、计划或账本。没有来源/模型失败/正文被截断都会明确提示，不能伪装成已联网核实。

## 情景确认与参考价

先生成一个待填写文件：

```powershell
python -X utf8 -m qmt review-template 000157.SZ
```

编辑 `data/drafts/000157.SZ.json`，逐项核查原始公告：业务、派息政策、正常化盈利、现金与债务、最新变化、匹配股数。每项需要来源 URL、公告日期、解释和已阅读标记。填写悲观、基准、较好三种情景的正常化 EPS、支付率、保守系数及依据，同时记录反对理由与失效事件；比例用小数。

```text
情景每股分红 = 正常化每股收益 × 利润支付率 × 保守系数
参考价上限 = 情景每股分红 ÷ 要求股息率
```

默认比较 **4% / 5% / 6% 税前股息率**，只是分析情景。不能直接拿经营现金流替代利润；不能把已除息的历史分红当成未来一定能取得的现金。

确认完成后，设置 `approved: true`、`status: "可进一步评估"`，再导入：

```powershell
python -X utf8 -m qmt review-import .\data\drafts\000157.SZ.json
```

程序会校验数据完整性、来源、三情景、确认日期和财务证据指纹。**新财报、分红记录或股本发生变化，或超过 30 天，旧确认自动失效。** 修改配置须换一个独立 `--workspace`，不能将新规则混进旧账本。指纹变化后重新生成/填写新草稿；已有草稿不会被自动覆盖。

由于尚不掌握你的本金、期限和持仓，程序不擅自生成精确买入量。股价满足已确认情景后，由你显式指定数量：

```powershell
# 仅示范命令；未满足研究及资金条件时会拒绝，不会跳过校验
python -X utf8 -m qmt plan --mode paper --symbol 000157.SZ --quantity 100 --scenario 悲观 --required-yield 0.05
```

计划仅下一交易日有效，包含限价；不追价。同日同股票同方向不重复创建，有未核对计划时不再开同一股票的新计划；买单预留现金和费用，并检查单股与行业金额上限。配置中的模拟本金 10,000 元、单股 2,000 元、行业 4,000 元都是虚构学习参数，不是个人仓位建议。

## 模拟成交和现金分红

下一交易日收盘后运行 `daily`，模拟按当天开盘价加不利滑点成交。开盘触及涨跌停、缺少必要数据、滑点价格超出实际范围或计划限价时，不假定成交。日线模拟不重建订单簿，也不保证能成交对应数量。

模拟费率来自 `config.json`：佣金 0.03%、最低 5 元、卖出印花税 0.05%、滑点 5bp。佣金为估计值，并非你的中信实际费率；过户费等若未包含在估计佣金中，须另校准。真实成交录入券商账单的总费用。

现金分红按**股权登记日持仓**核定资格，除息日起计入应收、派息日才进入可用现金；除息后买入不会获得此前分红。使用未复权成交/估值价格加实际现金分红，避免重复计算复权收益。重复运行不会重复派息。初始化账本之前及当日已经支付的历史分红不再追加入账，避免重复计入期初现金。

模拟分红是税前口径，不自动计算个人持有期股息税；送股、转增、配股等股份变动尚未自动记账，检测到送转股会暂停，不能继续把旧股数当真。完整收益评估需补齐公司行动及税费支持。

## 中信 APP 手动交易

先明确你愿意分配给这个策略的现金、单股和行业上限。以下数字是操作示例：

```powershell
python -X utf8 -m qmt init-manual --cash 10000 --max-position 2000 --max-sector 4000

# 若策略已有持仓，在生成第一条计划前登记；date 是实际取得持仓的日期
python -X utf8 -m qmt opening --mode manual --symbol 000157.SZ --quantity 100 --date 20261102

# 满足研究确认后，建立手动计划；程序不向券商发送委托
python -X utf8 -m qmt plan --mode manual --symbol 000157.SZ --quantity 100
```

`cash` 是已有持仓之外的可用现金；初始股票不再次扣现金。账本只能覆盖分配给此策略的资产，使用其他账户资金交易前需要重新核算，不应把不相关交易混进来。

在中信 APP 核对代码、实时价格、可用资金和计划有效日后自行决定是否提交限价委托。只有实际成交了，才回填：

```powershell
# plan 使用报告中的 ID；日期、数量、价格、总费用必须来自实际成交
python -X utf8 -m qmt fill --plan 1 --date 20261109 --quantity 100 --price 6.00 --fee 5.00 --reference 实际唯一成交编号
```

部分成交可分次录入，每笔使用不同的成交编号；同一编号同样内容重复录入会忽略，内容不同会报错。卖出检查 T+1，买入检查账本现金。不允许倒序补录跨日成交。录错后不要随便删除 SQLite 记录：先保留备份和券商交割单核对；首版不提供撤销已成交账目。

没执行或部分成交后已撤单：

```powershell
python -X utf8 -m qmt close-plan --plan 1 --reason 已核对成交且剩余委托已撤销 --broker-reconciled
```

这条命令**只关闭本地计划，不撤销券商委托**。手动账本不会因为日期过去就自动取消未核对计划。

对已经持有的股票，要退出时必须明确原因和限价，不因为股价跌破某条线自动卖出：

```powershell
python -X utf8 -m qmt plan --mode manual --side sell --symbol 000157.SZ --quantity 100 --price 6.00 --reason 经核实分红政策已改变
```

实际到账分红与后续补扣税分别录入：

```powershell
python -X utf8 -m qmt cash-event --kind dividend --symbol 000157.SZ --date 20261109 --amount 50 --reference 派息凭证号 --note 实际到账分红
python -X utf8 -m qmt cash-event --kind tax --symbol 000157.SZ --date 20261110 --amount -5 --reference 补税凭证号 --note 券商补扣税
```

不能用此命令记录入金并当成收益。真实账本不按假设派息自动加钱。成交与现金流水须按日期顺序录入，避免倒序改变已发生交易的可用余额。股票退出指数后，已有持仓仍可明确创建卖出计划。

## 范围与已知限制

- 实际覆盖范围和每家公司缺失的接口/字段显示在报告；搜索与 AI 草稿按需逐家公司运行。
- 金融企业保留为待核实，不套用工业现金流模型；首版未实现监管资本等专门数据门禁，不能自动放行金融股计划。
- 候选研究包含指数中的不同板块；执行仅支持沪深主板普通股。创业板、科创板、北交所的权限和交易单位尚未实现。
- 严格保留财报实质冲突，可能需要人工核对；不会为提高“通过率”补零或选有利版本。
- 不输出收益回测。使用当前成分与当前可见的修订财报倒推历史，会产生幸存者偏差和前视偏差。研究计算器的单元测试不证明收益。
- 行业分类仅作第一层集中度控制；基金重叠、雇主股票和共同经济驱动仍须人工纳入。
- 报告是本地 HTML；第一版通过命令行更新/录入，不包含公网服务或浏览器写入表单。

依赖、单位、许可及接口原文见 [UPSTREAM.md](UPSTREAM.md)。
