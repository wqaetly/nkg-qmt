# NKG 红利研究工作台

从**沪深主板**筛选低估值、可持续高股息、流动性强的公司，不要求属于中证红利指数，核查财报与分红，按悲观/基准/较好情景比较税前股息率参考价；每天自动完成机械规则评估、虚拟仓位分配、订单及次日模拟成交；中信 APP 手动成交仍使用独立账本。

研究方法来自 [dividend-stock-research](https://github.com/wqaetly/dividend-stock-research)，自动模拟是新增的、可复现的规则实验。允许没有合格候选。历史股息率只用于候选初筛，不能代替未来分红。只有估值、分红、流动性及资金规则同时满足才生成虚拟订单。

**不连接券商、不保存证券账户密码、不自动发单。** 初次运行创建独立自动模拟账本，当前默认 10 万元虚拟本金；手动实盘账本必须自行初始化。Python 3.10+，仅使用标准库，无需安装依赖。

最新完成并发布的独立历史实验为 **v38**：保留v37全部选股、财务与估值条件，只增加确认卖出后的一次补买。2014-12-31至2026-11-06的长期主方案年化 **3.26%**、最大回撤 **15.92%**、平均仓位 **29.74%**，期末净值146,309.35元，435笔成交；最多持有20只，期末7只。短期2022-12-30至2026-11-06年化4.81%、最大回撤4.77%。长期收益较v37略升，但回撤扩大；**两组完整年化均未达到10%目标**。股息现金未扣个人股息税，已观察历史不构成盲测，日常模拟仍采用原固定金额与现金流规则；详细同区间对照见文末v38记录。

**v36 财务失败退出实验**命令：`backtest --annual-pool --all-candidates --yield-rank --approved-annual-cash --three-year-cashflow --equity-limits --known-failure-exit`。月末已确认三年自由现金流不足覆盖分红、或短债超过现金与正经营现金流时，须继续检查后续财务字段、股数、价格和市场数据；资料完整才允许按原限价规则退出，不能再买入，也不生成这类失败公司的预计股息率。真实缺项、身份不明和行业变更仍冻结；年度候选建池、入场条件及交易执行不变，不叠加 `--pe-context`。长期组另加 `--long-history --position-freeze`。这是独立研究规则，默认日常和未指定退出选项的回测命令保持原行为；已登记的正式结果不得覆盖或重跑。

v38的586项代码测试、383,652项独立输入、账本及结果检查通过；完整封存见`data/diagnostics/v38-completed-manifest.json`。当前看板使用197只历年股票的原始K线、509张计划、435笔长期成交及逐日净值，预测诊断271条。三页静态检查408项及JavaScript语法检查通过；浏览器工具拒绝本地`file:`页面，尚未完成本轮视觉复核。当前仍有年度派息范围、财报版本等缺口，后续按公告逐项核实，不以放宽未知数据换取达标收益。

**v38补单规则。** 在上述v36命令后加`--after-sale-rebalance`启用独立实验：月末原买入目标因20只数量上限而未建单时，等待原卖单在下一交易日实际成交，收盘再核资金与仓位，最早再下一交易日补买一次。保留原股数和限价上界，重新检查整手、费用、10%现金与随净值变化的单股/行业预算；缺报价、送转改变股数口径或出现新月度信号时取消，不滚动追单。继续使用原月度财务资格及冻结名单，不声称每天重新评估财报。这是决策时的预算约束，股价随后变化仍可造成被动市值超额。正式两账户各运行一次，126份准备输入和全部190个月信号与v37一致；已完成版本不能覆盖重跑。

## 开始使用

在仓库目录执行（Windows PowerShell）：

```powershell
# 首次使用：复制配置，再填入你已有的服务凭据；已有 .env 则跳过此步
Copy-Item .env.example .env

# 每个交易日北京时间 21:00 后运行；首轮约数分钟，随后同日重复运行使用缓存
python -X utf8 -m qmt daily
Invoke-Item .\data\capital-100k\dashboard.html
```

本机本次安装已经创建 `.env`，不要覆盖。Tushare 直接使用 HTTP API，搜索使用 SearXNG 的 `/search?format=json` 和 `X-API-Key`，模型使用兼容的 `/chat/completions`。DeepSeek 默认关闭思考模式用于生成简短研究草稿。凭据、行情、账本和报告均被 Git 忽略；仓库只包含配置样例。

当前命令默认使用独立工作目录 `data/capital-100k/`，`start.ps1` 也打开这里的报告。旧 `data/` 中的账本、协议和结果全部保留；本轮仅复制复用行情缓存、公开研究资料及历史原始数据缓存，没有复制旧账本。新目录已使用真实数据完成 `daily` 和 `lab`，不把旧1万元账户的余额或收益迁入10万元实验。

也可运行 `powershell -File .\start.ps1` 完成更新并打开报告。21:00 前会明确暂停；节假日显示最近完整交易日，不能从休市日/旧报告新增计划。`--refresh` 可重新获取当日数据，用于晚到或修订数据。缺少字段、日期不符、接口无权限时会显示缺口，不用旧价冒充新价。

只查看已有结果：

```powershell
python -X utf8 -m qmt report
```

日常只展示最多 5 只重点观察股：持仓和未完成订单优先，其次 `research_watchlist`（默认宇通客车、青岛啤酒、伊利股份），剩余位置优先选择满足三项规则的公司。关注名单只保证被研究，不保证买入。股票是否买得起只影响下单，不影响研究资格。

可切换股票及近 30/60/120 根 K 线，用鼠标、触摸或左右方向键查看 OHLC 和成交量。每家公司展开后分别列出估值、持续高股息和流动性的依据与缺口。后台覆盖主板基础指标，再对通过估值的候选及关注/曾交易公司研究财报；页面明确展示各层数量，不能把财报批次声称为全市场深度研究。完整初筛记录保存在 `data/capital-100k/screen.json` 的 `selection_checks`；`daily --limit 3` 只调试财报批次，不运行自动模拟。

**目前不启用定时任务。** 策略仍在调整，需手动执行 `daily`；该命令内自动处理模拟流程，不连接券商。

## 二十只股票研究与年化目标

目标是研究低估值、持续高股息、流动性强的组合，检验能否达到 **10% 以上年化总回报**，并同时观察最大回撤、投入比例、成本和年度表现。10% 是待验证目标，不是承诺，也不是选参数时必须凑出的数字。当前采用用户确认的 **10 万元虚拟本金、最多 20 只模拟持仓**：普通研究名单最多20只，历史实验使用`--all-candidates`时研究池可超过20只；实际持仓上限仍为20只。保留10%现金，单股上限5,000元、单行业上限20,000元；初始每只目标预算约4,500元。合格候选不足或一手金额超限时保留现金，不凑满20只。网页每页仍显示5只，展示数量与持仓上限分开。

20只是本轮兼顾研究规模、整手交易和集中度的实验选择，并非量化行业统一标准。[Qlib官方策略示例](https://qlib.readthedocs.io/en/latest/component/strategy.html)使用 `topk=50`，只是另一种示例配置；[Investor.gov的分散化说明](https://www.investor.gov/introduction-investing/getting-started/asset-allocation)强调同时考察不同公司、行业和资产类别，单看股票数量不能证明风险已充分分散。

```powershell
# 使用当前完整初筛冻结20只研究名单，更新这些股票的K线
python -X utf8 -m qmt lab
# 使用已有搜索服务和AI中转补公开资料草稿；不上传个人账本
python -X utf8 -m qmt lab --enrich
# 准备独立历史名单并进行含费用的成交回放
python -X utf8 -m qmt backtest
# 从2014年末独立建池，另取更早财报与估值资料，再准备长期回放
python -X utf8 -m qmt backtest --long-history
# 财务门槛前置的独立实验；可同时加 --long-history
python -X utf8 -m qmt backtest --quality-first
# 年末重新筛选最多20只，使用一个账户连续回放；仍为手动运行
python -X utf8 -m qmt backtest --annual-pool
```

名单按机械门槛状态分组，组内按情景股息率排序，保留指定关注股，每行业至多三只；研究名单中的疑点不因排名被抵消，不足20只不强行补入不合格股票。名单与输入摘要保存在 `data/capital-100k/research/cohorts/`，同日冻结，不能悄悄修改后挑选有利结果。网页提供20只紧凑列表、每页5只、搜索、依据展开与K线切换。

v9复用现有财务门槛，在排名入池前检查五年连续盈利和现金分红、审计、三年现金覆盖及债务；先用建池日为截止日取财务数据，通过后才为这些股票补取后续回放资料。建池时允许“等待价格”，具体买入仍逐月检查估值、流动性和4%/5%/6%门槛，不强迫买足20只；无可核实候选则记录为受阻，不能用空名单的现金收益冒充成功策略。剔除理由与证据指纹保存在 `cohort.json`，资料待核实与已观察到风险分开记录。该变化是看到旧实验问题后提出的新假设，不能称为独立样本外改进；日常模拟账户仍沿用原规则。

这一方向参考[中证红利质量编制方案](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/20231208180546-931468_Index_Methodology_cn.pdf)对连续现金分红与盈利质量的重视，但没有复制其50只样本、六因子排名或权重算法。界面按各版本原始本金、区间和状态并列展示，保留受阻记录，避免只展示最新结果。

财务资料待核实可能来自供应商现在的历史覆盖缺口，不能推断该公司当年未披露或投资者当年无法取得。按公告日期筛选也不能自动消除此类样本偏差；质量版仍为诊断，不把剔除资料不完整公司后的结果当作可靠实盘预期。

年度版仅改变候选刷新：每个年末收盘以截至当日的财务和市场资料重选，下一交易日才可成交。每次名单与淘汰理由保存到父实验 `cohorts/日期/`；合并历史曾入池股票后，每档门槛只运行一次连续账本，不年度重置本金或拼接收益。已退出名单的股票仍保留从首次入池至结束的行情、分红及财务追踪，资料未知的既有持仓冻结，其他退出按下一交易日限价处理；重新入池有独立有效期。未来名单不能产生过去信号。

每期最多20只，历史涉及股票总数可超过20只，界面分开展示。行业继续沿用首次入池归属，发现变更会冻结并阻止新增，未猜测或覆盖旧标签。月末仍重新分配目标：除冻结持仓外，不再满足买入条件即退出；不能将 `exit_yield=3%` 理解为“持有到股息率低于3%才卖”。日常模拟的月初重配同样可能先于3%退出，3%只是额外退出检查。本轮未同时调整估值、现金流或股息门槛。

历史K线与日常模拟在同一图表切换来源，历史数据直接读取当前实验原始行情、信号计划及成交。历史视图不套用今天的研究参考价；可定位具体成交前后K线，信号日期与成交日期分别标记。缺少成功结果的门槛不展示虚构买卖。

长期实验从2009年起获取财务资料、从2012年起获取估值资料，让2014年底的决策有更早历史可参考；这些预热数据不计入2015年起的策略收益。不加 `--annual-pool` 时在起点冻结研究池；年度版每年末重新筛选，旧结果与原入口口径保留。此前已查看过部分历史表现，因此这里的留出段**不再是完全未见的数据**。年度结果与以每个月末、最终截至日为终点的滚动三年结果，只切分同一条固定策略净值曲线作稳定性诊断，不是逐窗重新建池、训练及验证。

v2、v3的既有1万元短期诊断仍保存在原 `data/backtests/`；v4、v5、v6的长期数据准备均已中断，不能称为已完成回测。v7-long已完成新目录的取数、诊断及报告渲染，不覆盖旧协议；4%/5%/6%三组策略均为 `blocked`，没有生成收益。当时两项输入冲突为600882历史行业与601088重复分红。v8根据神华2017年实施公告精确归并重复组成项，普通0.46元、特别2.51元、税前合计2.97元；保留原始行与指纹，未知事件不套用。600882在2014年名为华联矿业，接口的食品饮料标签与当时矿业资料冲突，仍保留阻断，不猜测申万代码或删除该股。ETF和零收益现金基准可独立算出，不能替代被阻断的策略结果。

当前历史实验仍是诊断。程序按申万成员的纳入/剔除区间匹配行业，检查正PE≤25、同行中位数及自身历史分位≤50%；不足5个同行样本、区间空缺或冲突时不作通过结论。**有日期区间不等于已经证明历史行业正确**，600882的反例说明仍需核对原始分类。行业仓位使用入池时标签，后续标签变更会冻结该股并暂停新增；日常 stock_basic 细分行业与申万一级也尚未统一验证。历史财报原始版本、停牌估值、退市退出和送转结算仍有缺口。费用使用至少0.1%的固定卖出印花税压力假设，并非逐日实际历史税率；分红税前。界面始终显示目标“待验证”，ETF线是未扣投资者费用的复权参考，不能冒充整手成交净收益。

搜索和AI只提供待核查研究草稿；接口无提示不等于原文已核实。所有命令均为手动触发，**定时任务仍然暂停**。

## 往年数据如何用于本策略

回测要回答的是：“如果当时只看到已经公开的信息，这套规则会怎样选择和成交？”不是把今天掌握的所有资料放回过去。可先读[Qlib的时间点数据说明](https://qlib.readthedocs.io/en/latest/advanced/PIT.html)和[QuantConnect研究指南](https://www.quantconnect.com/docs/v2/writing-algorithms/key-concepts/research-guide)；本项目借鉴数据处理原则，不引入它们的运行依赖。

| 环节 | 应怎样处理 | 本项目当前状态 |
|---|---|---|
| 原始数据 | 保存接口、参数、字段、取数时间及原始响应；按股票、交易日检查缺失、重复和条数截断。 | 已有本地原始缓存与检查，长期查询分年/分批。今天下载的历史记录仍可能已被供应商修订，缓存不能证明它就是当时版本。 |
| 财报日期与版本 | 报告期说明业绩属于哪段时间，公告日才决定何时可知。比如2024年年报在2025年4月发布，不能用于2024年底选股；修订版也只能从修订公开后使用。 | 已按 `ann_date` / `f_ann_date` 截止并检查冲突；尚缺完整原始公告版本、发布时间与版本替换链，不能声称完整PIT（当时可得数据）。[Tushare利润表定义](https://tushare.pro/document/2?doc_id=33) |
| 历史股息与未来分红 | 历史TTM股息率只是过去的派息指标；已宣布待实施股息和未来普通股息情景应分开。预案不等于现金到账，特别分红不能自动外推为每年都能支付。 | `dv_ttm`用于初筛，未来情景另算；年度DPS可能包含已公布实施方案但尚未除息的事件，不能解释为已收到现金。普通/特别分类和登记基准股数仍有代理值。[每日指标](https://tushare.pro/document/2?doc_id=32)、[分红日期字段](https://tushare.pro/document/2?doc_id=103) |
| 成交与总回报 | 用当时未复权价格检查一手金额和限价；登记日确定派息资格，除息日形成应收，派息日转入现金。复权曲线另作比较，不能再加同一笔现金股息。 | 已实现原价成交、现金分红分阶段记账，以及精确匹配已核实公告的送转股登记和上市；未知送转及不足一股的权益仍阻断，不擅自舍入。[日线口径](https://tushare.pro/document/2?doc_id=27) |
| 历史股票集合与行业 | 使用当时上市的证券，包括后来退市者；名称、行业和指数成员也应取当时有效版本。不能拿今天的20只股票回测十年前。 | 已查上市/退市/暂停上市列表并过滤历史日期；年度版按年末重建池、连续回放账户。行业冲突仍阻断，完整退市退出与残值处理尚未实现。[股票列表定义](https://tushare.pro/document/2?doc_id=25) |
| 缺失与停牌 | 无行情先查原因。只有确认停牌后才能采用明确的持仓估值规则，停牌不允许成交；未知缺失不能补成0，也不能靠删除股票让回测通过。 | 历史账户已支持逐日公告确证的全天停牌持仓按此前真实收盘价估值，不生成行情或成交；未知缺口、原始行情冲突或跨除权除息仍阻断，尚无全市场完整停牌证明。Tushare日线在停牌期间不返回记录。 |

验证按时间顺序推进：先明确规则与开发期，再固定规则检查更晚时段。每次改门槛、名单或数据修正都保留版本和原因，不能只保留收益最好的一次。Bailey等人的[《回测过拟合的概率》原论文](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)指出，反复试验后的优胜结果存在选择偏差，单留一段历史也不能自动解决；本文档不表示已实现论文的PBO/CSCV检验。

目前可以检查成本、闲置现金、年度表现与重叠三年窗口，但还不能把它们叫作独立样本外验证。往年行情增加到十余年，有助于暴露不同市场时期的问题；它不会自动修复财报版本、行业归属或公司行动错误。先解决输入和交易口径，再讨论策略是否达到年化目标。


## 每日自动模拟

运行 `python -X utf8 -m qmt daily` 会按顺序完成：取交易日历、主板列表、行业估值与 20 日成交额 → 读取截至日已披露财务 → 结算此前订单与分红 → 按当日收盘价估值 → 运行规则 → 分配目标与生成下一交易日订单 → 更新最多 5 只观察股 K 线及报告。

自动账本位于 `data/capital-100k/auto/value-dividend-v3/ledger.sqlite3`，与当前工作目录的 `data/capital-100k/ledger.sqlite3` 手动指定计划和真实成交隔离；旧 `data/ledger.sqlite3` 保持原状。自动规则不写 `approved`，不生成“人工核实”结论，不能绕过手动交易的研究门禁；搜索或 AI 的输出不参与机械订单决策。

规则在 `automatic.json`，当前为 `value-dividend-v3` 的可审计实验假设，门槛可调整，但不代表上游研究仓库给出的买入规则：

- 全市场基础初筛限沪深主板、非 ST/退市标记、正 PE，历史 TTM 股息率至少 3%，PE 不高于同行业正 PE 中位数（至少 5 个同行样本）。不按低股价或低净值选股，PB 仅供背景参考。
- 低估值还要求近三年正 PE 历史分位不高于 50%（至少 250 个有效日，不含当日与未来数据），机械盈利 PE 不超过 25 倍。历史只计正 PE、同行分类较粗，都是研究代理，不等于内在价值或安全边际。
- 流动性：最近 20 个交易日成交额中位数至少 5,000 万元，至少 18 日有成交且当日有成交；缺失/停牌日保留在分母中。Tushare `amount` 的千元单位转换为元。快照明显不足或重复会暂停。
- 财报研究要求非金融企业、五个连续完整年度利润、扣非、派息、审计资料齐全。金融企业需另建监管资本模型，当前不自动买入。关注名单与既有计划跳过初筛淘汰以显示具体原因，但不能跳过买入门槛。
- 盈利代理取近三年 `min(归母利润, 扣非利润)` 的中位数、最近完整年度较低利润、TTM 归母、TTM 扣非四者最小值，再除以当前总股数。TTM 用上年全年加本期累计减上年同期，不把单季乘四。这只是机械代理，**不是已经核实的正常化盈利**。
- 历史派息总额用年度已实施 DPS × 年末总股数估算（年末股数不一定等于登记日股数，属于近似）。基准支付率取近三年支付率中位数，不再统一压到 70%。任一年估算普通派息超过利润则转入待研究，核查特别分红、留存收益与政策，不断言公司不合格。已核实的特别分红从盈利派息代理中剔除，实际现金记账仍使用总额；其他未分类记录仍是待人工核实的代理，不能保证已排除所有特别分红。
- 最近年度简化自由现金流为正、三年合计覆盖估算派息，资产负债率不超过 70%；三年覆盖不足或短期到期债务超过货币资金加上年经营现金流时转入待核实，补查定存、金融资产、资本开支与借款安排；不直接认定偿债或分红能力不足。
- 三情景分别为盈利代理的 80%/100%/110%，支付率的 90%/100%/100%，额外保守系数均为 1。**基准情景 5% 税前股息率**作为买入价格门槛；悲观情景另列，不用于声称最低收益。
- 10 万元虚拟本金，单股金额上限 5,000 元、单行业 20,000 元、持股最多 20 只。保留 10% 现金，每个目标预算为 `min(单股上限, 总资产×90%÷20)`，初始约 4,500 元；按 100 股向下取整。不足一手或合格公司不足时保留现金，不减少现金底仓或放松门槛凑单。
- 首次运行及每月首次成功运行时确定目标股数，其他交易日检查风险与未完成目标，不因日内排名变化频繁轮换。财务风险规则明确失败或基准股息率低于 3% 时退出；数据缺口冻结相关持仓并暂停新增，不把未知当成经营恶化。
- 买入限价取参考上限与收盘价上浮 1% 的较低者；卖出限价为收盘价下浮 1%。按下一交易日开盘加不利滑点模拟，限价不满足、触及涨跌停、超出日内范围或超过日成交量 1% 时不成交。缺失必要行情会暂停，下一次数据恢复后幂等补结算。未成交目标可于后续交易日重试。
- 不预支未成交卖单的资金，不允许实际持仓与待买入股票合计超过 20 只。账户配置、规则和首次完成的当日决策写入 SQLite；重复运行不重复下单。同日 `--refresh` 可更新行情，但不重写已经冻结的当日交易决策。

v3连同手动计划主账本一起使用新工作目录 `data/capital-100k/`，原 v1 的 `data/auto/` 及 v2 的 `data/auto/value-dividend-v2/` 账本与历史不覆盖、不合并收益；不向旧1万元账本补入9万元后继续计算同一条收益。此后修改同版本规则仍需要用新的 `--workspace` 开独立实验，旧实验保留。示例：`python -X utf8 -m qmt --workspace data/experiment-3 daily`。不要根据几天结果反复挑参数，再把挑中的历史收益当成验证。

## 情景确认与参考价

```text
情景每股分红 = 正常化每股收益 × 利润支付率 × 保守系数
```

## 模拟成交和现金分红

下一交易日收盘后运行 `daily`，模拟按当天开盘价加不利滑点成交。开盘触及涨跌停、缺少必要数据、滑点价格超出实际范围或计划限价时，不假定成交。日线模拟不重建订单簿，也不保证能成交对应数量；订单超过当日成交量的 1% 会拒绝假定成交。

模拟费率来自 `config.json`：佣金 0.03%、最低 5 元、卖出印花税 0.05%、滑点 5bp。佣金为估计值，并非你的中信实际费率；过户费等若未包含在估计佣金中，须另校准。真实成交录入券商账单的总费用。

现金分红按**股权登记日持仓**核定资格，除息日起计入应收、派息日才进入可用现金；除息后买入不会获得此前分红。使用未复权成交/估值价格加实际现金分红，避免重复计算复权收益。重复运行不会重复派息。初始化账本之前及当日已经支付的历史分红不再追加入账，避免重复计入期初现金。

模拟分红是税前口径，不自动计算个人持有期股息税；送股、转增、配股等股份变动尚未自动记账，检测到送转股会暂停，不能继续把旧股数当真。完整收益评估需补齐公司行动及税费支持。

## 中信 APP 手动交易

先明确你愿意分配给这个策略的现金、单股和行业上限。以下1万元数字仅演示手动账本命令，与当前10万元虚拟实验相互独立：

```powershell
python -X utf8 -m qmt init-manual --cash 10000 --max-position 2000 --max-sector 4000

# 若策略已有持仓，在生成第一条计划前登记；date 是实际取得持仓的日期
python -X utf8 -m qmt opening --mode manual --symbol 000157.SZ --quantity 100 --date 20261102

# 满足研究确认后，建立手动计划；程序不向券商发送委托
python -X utf8 -m qmt plan --mode manual --symbol 000157.SZ --quantity 100
```

`cash` 是已有持仓之外的可用现金；初始股票不再次扣现金。账本只能覆盖分配给此策略的资产，使用其他账户资金交易前需要重新核算，不应把不相关交易混进来。

在中信 APP 核对代码、实时价格、可用资金和计划有效日后自行决定是否提交限价委托。只有实际成交了，才回填：

```powershell
# plan 使用报告中的 ID；日期、数量、价格、总费用必须来自实际成交
python -X utf8 -m qmt fill --plan 1 --date 20261109 --quantity 100 --price 6.00 --fee 5.00 --reference 实际唯一成交编号
```

部分成交可分次录入，每笔使用不同的成交编号；同一编号同样内容重复录入会忽略，内容不同会报错。卖出检查 T+1，买入检查账本现金。不允许倒序补录跨日成交。录错后不要随便删除 SQLite 记录：先保留备份和券商交割单核对；首版不提供撤销已成交账目。

没执行或部分成交后已撤单：

```powershell
python -X utf8 -m qmt close-plan --plan 1 --reason 已核对成交且剩余委托已撤销 --broker-reconciled
```

这条命令**只关闭本地计划，不撤销券商委托**。手动账本不会因为日期过去就自动取消未核对计划。

对已经持有的股票，要退出时必须明确原因和限价，不因为股价跌破某条线自动卖出：

```powershell
python -X utf8 -m qmt plan --mode manual --side sell --symbol 000157.SZ --quantity 100 --price 6.00 --reason 经核实分红政策已改变
```

实际到账分红与后续补扣税分别录入：

```powershell
python -X utf8 -m qmt cash-event --kind dividend --symbol 000157.SZ --date 20261109 --amount 50 --reference 派息凭证号 --note 实际到账分红
python -X utf8 -m qmt cash-event --kind tax --symbol 000157.SZ --date 20261110 --amount -5 --reference 补税凭证号 --note 券商补扣税
```

不能用此命令记录入金并当成收益。真实账本不按假设派息自动加钱。成交与现金流水须按日期顺序录入，避免倒序改变已发生交易的可用余额。股票退出指数后，已有持仓仍可明确创建卖出计划。

### v21 预计股息率排序对照

保留原门槛模式，新增独立 `--yield-rank` 实验。主比较固定为“保守盈利、预计5%门槛”对“同一保守盈利、预计股息率排序”；TTM另作配对敏感性，不能跨口径挑选最高收益宣称成功。两种模式都检查全部年度财务合格候选，最多持仓20只；10万元本金、10%现金预留、单股5000元及行业20000元配置上限不变。相同数据、年度名单、月末检查、费用和下一交易日成交规则一起冻结后再回放。

```powershell
python -X utf8 -m qmt backtest --annual-pool --all-candidates
```

排序模式取消预计股息率至少5%和对应估值参考价的买入拦截。每月对仍通过财务、估值、流动性、历史TTM股息率至少3%、名称及行业核查的当期成员，按预计股息率降序、股票代码升序排列，**把完整候选列表交给分配器**；遇行业额度或整手预算不足时继续检查后续股票，不提前截断前20名。订单上限明确为信号日未复权收盘价×1.01，向下保留两位小数。5%情景价格仅留作研究参考。月末不满足完整资格者退出，待核实持仓仍冻结，未混入日常3%退出规则。

这是相对排名，入选股的预计股息率可以低于5%，也可能低于3%；历史股息率与预计股息率不是同一字段。它只作为独立对照，日常模拟仍使用原来的绝对门槛。[中证红利官方方法](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/932021_Index_Methodology_cn.pdf)按过去三年平均现金股息率排序取100只，并有自己的分红资格及旧样本缓冲；[中证红利质量官方招募书附件三](https://static.cninfo.com.cn/finalpage/2026-05-29/1225335168.PDF)则按财务质量综合分取50只。这些资料支持“资格筛选后相对排序”的方法参考，**不证明本项目预测公式、20只或10%目标有效，也不是对上游策略或官方指数的复刻**。
