# 中长期投资早午盘研究

让数据决定研究对象，让 Gemini 查证业务与事件，让 Codex 复算并形成最终研究意见，由用户决定并执行交易。

## 默认设置

- 持有周期为数月至更久；北京时间约 10:00、14:00 是报告目标时间，不是买卖频率。
- 默认覆盖 A 股股票及境内 ETF；按用户关注扩展港股、海外 ETF 和 QDII。跨市场数据权限和交易资格分别核验，不能假定 Fuyao 的 A 股接口覆盖全部市场。
- 沿用最近已确认的关注池与研究目标。首次没有关注池时，先从 A 股中长期质量、现金流、估值及主流宽基/红利 ETF 对比入手，明确实际覆盖范围；不要声称已穷尽全市场。
- Gemini 使用用户指定且已连接、已登录的 Chrome 配置，直接操作网页。不要改成 Gemini API、桌面点击、读取浏览器凭据或私有网络接口。
- 历史聊天用于理解研究偏好；旧截图、旧持仓金额与旧建议均不代表当前事实。个性化仓位计算需要最新持仓、币种、可用资金与风险约束；缺失时先完成标的研究，仓位建议保留为条件方案。
- 本 skill 不下单、不撤单、不修改交易账户或模拟账本，不自动开通券商服务。目标时间本身不是已配置的自动化；仅在用户要求定时运行时使用应用的自动化工具。

## 执行流程

1. **确定这次研究。** 读取当前北京时间、相关交易所日历、最近一期本地报告。记录报告目标、信息截止时间、市场、候选范围和数据缺口。午盘优先回答相对早盘发生了什么变化；无变化可以维持判断，不为每日两份报告制造交易。
2. **用数据初筛。** 读取 [数据来源与本机接入](references/data-sources.md)。用最近完整交易日数据筛选，再以带时间戳的盘中快照校验价格。按业务质量、财务/现金流、估值、资本配置和重大风险说明入选及排除原因。股票与 ETF 分别比较，不把低 PE、高股息或短线涨幅当成单独的买入理由。默认精选 3–5 个值得深查的候选；用户指定列表则覆盖其列表。数据不全应标成“待补充”，不能当作数值 0 或已通过筛选。
3. **整理公开研究包。** 保存候选代码/名称/市场/币种、指标原值和单位、期间与公告时间、来源、检索时间、计算公式、疑点和反方论点。把公开标的信息和私人组合信息分开；默认只向 Gemini 发送公开信息，不发送账户、金额、成本、截图、密钥或私人历史聊天。
4. **执行 Gemini 深度研究。** 读取 [Gemini 网页流程与提示词](references/gemini-workflow.md)。审阅研究计划后启动，读取完成报告及引用；聊天回复、研究计划和研究进度不能冒充完成的 Deep Research。记录会话链接与完成状态。
5. **Codex 独立复核。** 打开支持关键结论的原始公告、财报、基金文件、交易所或监管页面，核对日期和适用范围。复算会改变行动的数字；说明采纳、修正或拒绝哪些 Gemini 结论及原因。研究完成后刷新行情；报告发布时不能沿用开始研究时的报价冒充现价。两家 API 相同数值也可能来自共同上游，不算两份独立证据。
6. **形成明确研究意见。** 依 [报告规范](references/report-format.md) 给出“可考虑分批 / 等待条件 / 持有观察 / 降低敞口 / 回避 / 证据不足”，并说明适用条件、反证、失效点、下次复核事件。对于长期持有，区分企业价值变化与单纯股价波动；技术面主要辅助执行。允许结论为“今天无需操作”。

研究红利股票时，读取同库的 [dividend-stock-research](../dividend-stock-research/SKILL.md)，复用分红持续性、现金覆盖及情景买价方法；由本 skill 统一编排数据、Gemini 和最终报告，不重复启动整轮研究。两者的数据接入遵循本次用户选择与实际可用接口。ETF 不直接套用个股每股盈利派息模型。若该技能未安装，仍按本 skill 完成可支持的研究，明确无法使用的辅助资源。

## 时间与失败处理

10:00/14:00 报告可分别从约 09:30/13:30 启动，实际提前量根据研究耗时调整，不承诺固定耗时。首次建立完整底稿；其后刷新数据与新增公告，Gemini 聚焦变化和未解问题，避免每日重做全部背景。

权限不足、登录失效、额度耗尽或网页失败时，保留已完成的数据研究和准确状态。可做一轮有针对性的恢复；仍不成功则说明具体阻塞，不无限刷新或绕过限制。没有 Gemini 完成结果时只能发布标明缺少该环节的阶段报告，不静默替换为普通聊天。到报告时间尚未完成，先交付事实更新与待研究项，后续补充；不得倒填时间或把缺失环节写成成功。

## 本地结果

以当前 `nkg-qmt` 工作区为项目根目录，不依赖固定盘符。在其已忽略的 `data/agent-research/YYYY-MM-DD/HHmmss/` 中保存本次公开研究包、Gemini 提交提示词及取得的报告/引用、最终 `report.md`。记录前一期报告路径以支持午盘差异比较；每次新目录，不覆盖旧记录。只存实际取得的内容，未完成环节在报告中注明。私人组合信息如确有需要仅本地保存，不能复制进 skill 或云端记忆。

如果当前机器没有该项目，使用当前工作区独立的研究输出目录并说明，不擅自克隆或迁移项目。已有只读数据函数可用时复用；本库没有机械策略、回测或交易执行入口，不读取旧模拟账本作为真实持仓或投资证据。
